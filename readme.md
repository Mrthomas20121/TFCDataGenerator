# TFC Data Generator
TFC Data Generator is a minecraft data generator written specifically for 1.20.1 tfc.
## Why does this exists?
TFC's own Data generator(before 1.21.1) is written in python, I did not want to work with their datagen so I made my own for tfc metallu U.
## Can I use this for my own mod or tfc addon?
Feel free to modify this for your own mod but I will not help you. you're on your own.
